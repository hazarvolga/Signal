# ⚡ Signal — AI Marketing Automation & Signal Platform

> **[STACK: Vite 6, React 19, TypeScript 5.8, Express 4, Prisma ORM, Monaco Editor, MJML 5, Vitest]**
> **Project Scope:** Enterprise AI Email & Marketing Automation Engine  
> **Category:** 🧪 Lab / Production-Ready Microservice  
> **Quality Standard:** Engineering Readiness Gate (10/10 Rating)

---

## 🎯 Architecture Overview

- **Frontend:** React 19 + TypeScript + TailwindCSS v4 + Motion
- **Code Editor:** `@monaco-editor/react` for custom MJML & Liquid email templates
- **Backend API:** Express 4 REST & Webhook Dispatch Server (`server.ts`)
- **Template Engine:** LiquidJS + MJML 5 + Custom Sandbox Executor (`worker_threads`)
- **Database:** Prisma ORM (PostgreSQL & SQLite Fallback Support)
- **Quality Assurance:** Vitest 4 + Pino Logging + Sentry
