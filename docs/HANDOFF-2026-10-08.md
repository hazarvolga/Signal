### C. Uçtan Uca Fonksiyonel Köprüler (Workflow Bridges)

#### 1. Form & Contact ➔ Otomasyon Tetikleme Zinciri

- **Sorun:** Daha önce otomasyonlar yalnızca Shopify webhook veya manuel tetiklemelerle çalışıyordu. Form dolduran veya yeni eklenen aboneler otomasyon akışlarını başlatmıyordu.
- **Çözüm:**
  - [`src/routes/contacts.ts`](../src/routes/contacts.ts): Yeni contact oluşturulduğunda `CONTACT_CREATED` ve `SIGNUP` event'leri `createEventAndBroadcast` üzerinden fırlatılır.
  - [`src/routes/forms.ts`](../src/routes/forms.ts): Genel form gönderildiğinde `FORM_SUBMITTED` ve `SIGNUP` event'leri otomasyon kuyruğuna iletilir.
  - [`src/pages/Automations.tsx`](../src/pages/Automations.tsx): Statik mock tag dizisi kaldırıldı, veritabanındaki gerçek etiketler (`api.getTags()`) yüklendi.

#### 2. Güvenli Toplu İçe Aktarma (Bulk Import Spam Koruması)

- **Kural:** 10.000 kişilik bir liste içeri aktarıldığında anında 10.000 "Hoş Geldin" e-postası fırlatılıp kotanın bitmesini veya IP'nin spam'e düşmesini önlemek amacıyla ikili seçenek uygulandı:
  - Varsayılan: Toplu içe aktarma otomasyonları tetiklemez (`triggerAutomations: false`).
  - İsteğe Bağlı: Yönetici dilerse `triggerAutomations: true` göndererek otomasyonları çalıştırabilir.

#### 3. Segment ➔ Kampanya Köprüsü

- Segmentler sayfasından (`/audiences` veya `/data-layer`) doğrudan seçili segmente kampanya açma butonu eklendi (`/campaigns?segmentId=...`).
- Kampanya oluşturma sihirbazına **İkili Hedefleme Seçeneği** kazandırıldı:
  - **Snapshot (Anlık Çekim):** Kampanya kaydedildiği anda segment kuralına uyan kişileri hemen tespit eder ve dondurur.
  - **Dynamic (Dinamik Değerlendirme):** Kampanya gönderim anında kuralı yeniden çalıştırarak en güncel kitleye gönderim yapar.

#### 4. Yetkilendirme (Auth Bridge) ve Public Sayfa Düzeltmeleri

- `FormBuilder`, `LandingPages`, `GrowthEngine` ve `Audiences` sayfalarında token taşımayan ham `fetch` çağrıları JWT token taşıyan güvenli `apiFetch` servisine geçirildi (401 hataları giderildi).
- `src/pages/Unsubscribe.tsx`: Sahte `setTimeout` mock'u kaldırıldı; gerçek `api.updatePublicPreferences` ve `api.getPublicPreferences` ile veritabanında izin/tercih güncellemesi bağlandı.
- `src/routes/flows.ts`: `/api/amp/submit` rotası oturum şartından muaf tutularak dış e-posta istemcileri için güvenli, tenant izolasyonlu ve rate limit korumalı hale getirildi.

- **Shopify (`/integrations/shopify`):**

- **WooCommerce (`/integrations/woocommerce`):**
  - Alanlar: Mağaza URL'i, REST API v3 Consumer Key (`ck_...`) ve Consumer Secret (`cs_...`).
  - Fonksiyonlar: WooCommerce API ping testi, katalog senkronizasyonu.
- **HubSpot (`/integrations/hubspot`):**
  - Alanlar: Private App Access Token (`pat-na1-...`).
  - Fonksiyonlar: CRM Contacts erişim testi, kapsam (scope) rehberi.
- **Zapier (`/integrations/zapier`):**
  - Fonksiyonlar: SIGNAL'den Zapier Catch Hook'a giden örnek JSON yükü (sample payload), Zapier'den SIGNAL'e veri basacak API URL'i (`/api/contacts`) ve tarifler.
- **Twilio SMS (`/integrations/twilio`):**
  - Alanlar: Account SID (`AC...`), Auth Token, Gönderici Telefon Numarası / Messaging Service SID.
  - Fonksiyonlar: Twilio API canlı hesap ping testi.
- **WhatsApp Meta (`/integrations/whatsapp`):**

  - Fonksiyonlar: Meta Graph API v21+ telefon doğrulama testi.

#### 2. Dış Dünyaya Sinyal Gönderen Outbound Webhook Motoru

- [`src/services/webhookDispatcher.ts`](../src/services/webhookDispatcher.ts) devreye alındı.
- Sistemde bir olay (`contact.created`, `order.placed`, `campaign.sent`, vb.) tetiklendiğinde `createEventAndBroadcast` üzerinden organizasyonun aktif kayıtlı webhook'larına asenkron HTTP POST istekleri fırlatılır.
- **HMAC Güvenliği:** Her paket `X-Signal-Signature-256` ve `X-Signal-Timestamp` başlıklarıyla imzalanır.
- **Kayıt ve İzleme:** Tüm gönderim sonuçları (durum kodu, hata mesajı, süre) `WebhookLog` tablosuna işlenir.

#### 3. Production API Access (Harici Geliştirici Anahtarları)

- `/integrations` sayfasındaki sahte kart kaldırıldı.
- Kullanıcı canlı `sig_...` formatında API anahtarı üretebilir, anahtarı gösterip gizleyebilir, tek tıkla kopyalayabilir.
- [`src/middleware/auth.ts`](../src/middleware/auth.ts) Express katmanında güncellendi:
  - `x-api-key: sig_...` veya `Authorization: Bearer sig_...` başlığı tespit edildiğinde SHA-256 hash'i doğrulanır, ilgili tenant organizasyonu (`organizationId`) bağlanır ve API çağrısı güvenle icra edilir.
